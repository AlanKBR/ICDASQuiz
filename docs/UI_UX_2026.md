# ICDASQuiz — interface responsiva 2026

## Fonte visual

Handoff fornecido em 14/11/2026: `icdasquiz-design-handoff.zip` (pacote de protótipos e 28 capturas desktop/mobile). O pacote integral permanece na área de trabalho do servidor; apenas os componentes e estilos de produção entram no repositório e na imagem.

Direção aprovada: interface mobile-first, fonte Onest auto-hospedada, visual claro verde-menta/lilás, foco em fotografia clínica e redução de texto sem remover critérios necessários. A UI usa Flask/Jinja + JavaScript progressivo, não um frontend autônomo.

## Assets e build

Os estilos editáveis ficam em `src/css/{design-tokens,design-components,redesign}.css`, gerados para um único `static/css/app.css` com `python3 tools/build_web_css.py`. Verifique consistência com `python3 tools/build_web_css.py --check`. O CSS da árvore permanece isolado e carregado apenas nas páginas que o utilizam. A antiga cadeia Tailwind/custom/UI/landing e o runtime Node/Tailwind foram removidos do aplicativo. O bundle não depende de ferramenta de build de terceiros.

A fonte variável Onest usa um nome derivado do hash do conteúdo (`onest-cb4d777c.woff2`) e a URL do preload coincide exatamente com a URL de `@font-face`, evitando downloads duplicados. Para trocar a fonte, gere um novo nome com o hash real e atualize os dois caminhos.

## Contrato preservado

- Os códigos 0–6 e explicações são servidos de `descricoes.json`; nenhum dado clínico ou imagem foi substituído por conteúdo sintético do protótipo.
- O quiz mantém 10 imagens sem repetição, correção e persistência no servidor, CSRF, rate limits, cookie seguro e versão do acervo. O preview de duas imagens da landing é local e não registra resultados.
- Feedback e revisão aparecem **somente após** a resposta da respectiva fotografia; a revisão de tentativa concluída exige o participante da sessão, além do ID da tentativa.
- A galeria filtra o acervo real, sem API adicional. O placar preserva a publicação de nome declarado e desempenho já existente.
- O dashboard continua protegido por `ADMIN_PASSWORD` e mostra dados reais e agregados de PostgreSQL/SQLite; o contador de origens de rede usa HMAC de IP e não afirma identidade/dispositivo. Filtros: 30 dias, 90 dias ou tudo.
- A árvore de tratamento reutiliza o modelo e a lógica existente e permanece identificada como material em revisão clínica, sem efeito no quiz.
- Nenhuma migração Alembic ou mudança de state foi exigida. Produção permanece no mesmo owner e bordo Cloudflare/Sablier.

## Verificação

`python -m pytest tests.py -q`, `node --check` nos scripts modificados, compilação dos templates Jinja, Docker build e smoke test isolado com SQLite e rede `none`, incluindo `/health`, landing, quiz, galeria, placar, árvore e assets locais. Os testes incluem fluxo de 10 respostas, não vazamento de gabarito, autorização de revisão, métricas reais, filtros e políticas de segurança.

Rollback de publicação: restaurar a tag/imagem anterior no owner do serviço e executar seu `reconcile`; o banco não precisa de rollback por se tratar apenas de UI e agregações read-only. Backups de banco e Git são externos ao repositório.
