ICDAS Quiz

O que vem à mente

Quando se fala em ICDAS, pensamos nesta ficha.

Mas o ICDAS não é só isso.

International Caries Detection and Assessment System

  • Um sistema internacional, com critérios padronizados para detectar e classificar a cárie.
  • Inclui as lesões iniciais, antes de existir cavidade.
  • Permite comparar examinadores e estudos.

Ismail et al., 2007; ICDAS Coordinating Committee, 2009.

✦

Essa visão incompleta, comum entre nós alunos, me motivou a criar uma ferramenta para entender melhor o sistema.

06Conclusão

O software está no ar. Agora, a pesquisa.

Limites deste trabalho

  • Não mede aprendizagem.
  • A foto não permite secar, sentir textura ou mudar o ângulo.
  • Dados de uso informais, sem controle de quem respondeu.
  • Verificação interna, sem validação externa.

À disposição

O ICDAS Quiz fica aberto para o ensino.

Para o professor Rodrigo e demais professores aplicarem em sala de aula, e para qualquer aluno que queira aprender.

Um convite

Que outro aluno continue este trabalho.

Com uma pesquisa aplicada, aprovada pelo CEP, para medir se o treino melhora a classificação, principalmente nos códigos 1 e 2.
